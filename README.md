# draw-physics 🎨

> **draw.iamblwb.com** — AirDraw-style physics drawing in the browser

Draw with your mouse or finger, release — and watch shapes fall with realistic physics!

## Features

- 🖱️ Mouse + Touch drawing
- ⭕ **Circle detection** → bouncing ball
- 📏 **Straight line** → rigid stick that falls and topples  
- 🌊 **Curved line** → rope segments that swing and drape
- 💫 Dark glow aesthetic with particle effects
- ⌨️ `R` to clear canvas, `Space` to flip gravity

## Tech

- **Matter.js** — 2D physics engine (gravity, collisions, constraints)
- Pure HTML/CSS/JS — single `index.html`, no build step
- CDN-only, no backend
